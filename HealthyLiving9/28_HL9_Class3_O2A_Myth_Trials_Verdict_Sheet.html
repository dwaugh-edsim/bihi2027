Six Things To Know IF YOU ONLY REMEMBER SIX
  1. Most STBBIs have no symptoms. Feeling fine is not a test result. Only a test tells you.
  2. They pass through more than sex. Oral sex, and skin-to-skin contact, are real routes. Number of partners is not the issue — one partner can pass one on.
  3. Hormonal birth control prevents pregnancy only. Condoms prevent STBBIs. Some methods do both; the shot does not protect against STIs.
  4. Some are curable, some are manageable. Chlamydia and gonorrhea are curable with antibiotics. HIV and herpes are managed, not cured. You can catch the same one twice.
  5. Vaccines exist for some. HPV and hepatitis B — prevention, not treatment.
  6. You can get care confidentially in Nova Scotia. STI testing and birth control do not require a parent's permission. 811 and Youth Health Centres can point you to local options.
When Is It Actually "It Depends"?
01It depends = a real condition
"It depends" only counts when you can name the condition: which method, which STI, which kind of consent.
02Partial truth
True for some, false for others. Often the most dangerous kind, because it sounds certain.
03Real uncertainty
The evidence is genuinely still moving. Rare — and being able to say which is the skill.
04Not a hedge
"It depends" is not a safe middle answer. If you cannot name the condition, it isn't the right tick.
