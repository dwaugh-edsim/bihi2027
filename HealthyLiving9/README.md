## 1. Directory Purpose & LLM Context

This folder contains all curriculum units, interactive telemetry dashboards, forensic case files, student ledgers, and facilitation keys for **Grade 9 Healthy Living**.

The signature instructional design of this course is **Forensic Quantitative Health**. Instead of passive lectures, students act as clinical forensic auditors analyzing real-world circadian disruption, compounding sleep debt, screen-time telemetry, dopamine feedback loops, and neurobiological stress responses using exact mathematical formulas.

## 2. Key Modules & Flagship Applications

### A. Unit 1: Sleep Telemetry, Circadian Biology & Phone Forensics
* **Core Formula:**
  $$\text{Compounding Sleep Debt} = \text{Deficit per School Night} \times 5 \text{ days}$$
  $$\text{Annual Lost Time} = \frac{\text{Weekly Deficit} \times 52 \text{ weeks}}{24 \text{ hours/day}}$$
  *(e.g., A student losing 45 min/night incurs a 3.15 hr weekly deficit, which equals 6.8 full 24-hour days of lost restorative sleep every year).*

## 4. Technical Constraints for LLMs Modifying This Folder

1. **Strict A4 Print Fidelity:** Student ledgers and case files (`14_HL9_...`, `18_HL9_...`) are designed to print cleanly on double-sided 8.5×11 or A4 paper without accidental page overflowing. Maintain page break rules (`page-break-after: always`).
2. **Formula Integrity:** When updating sleep or health telemetry formulas, preserve standard clinical metrics (recommended teen sleep: 8.5–9.5 hrs; REM/NREM sleep architecture; blue light 450–480nm suppression of melatonin).
3. **No External Dependencies:** Keep all HTML apps self-contained with embedded CSS and vanilla JS.
