## 1. Directory Purpose & LLM Context

This folder serves as the **operational control room, turnkey launch binder, and immediate delivery package** for the start of the 2026–2027 school year in Room 8.

It houses clean, production-ready duplicates and master prints of every Day 1 deliverable organized numerically (`00_` through `20_`). It is designed so that a teacher (or substitute teacher) can open `index.html` or this directory and instantly execute the entire first cycle of classes without navigating between separate subject repositories.

## 3. Technical Architecture & Design System

1. **Self-Contained Portability:** Every HTML file in this directory is fully compiled and runnable standalone from a USB thumb drive, local disk (`file:///`), or local web server.
2. **Numeric Prefix Convention (`00_` to `20_`):** Files are prefixed by chronological launch order for intuitive sorting during high-intensity school days.
3. **Print First Design:** Every student worksheet includes `@media print` CSS rules targeting standard 8.5×11 or A4 paper with exact margins, ensuring zero clipped borders or misaligned lines when printed on school copiers.
