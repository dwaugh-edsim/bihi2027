Document templates

Four print-ready student documents on one shared design system: the theme in Student_System/doc_theme.css. Every one is A4, every one prints to the page count it declares, and every one uses the same teal / ink / warm palette and type scale as the newer course materials.

How the theme works. The templates link ../Student_System/doc_theme.css. Change a token there and every document follows — that is the point of the file. If you copy a template into a course folder, keep the relative path correct for its depth (one level down: ../Student_System/doc_theme.css; two levels down: ../../Student_System/doc_theme.css). Need a portable single file? The inliner in the private repo produces one: python ../bihipri-27/tools-priv/build_doc_template.py --inline <file.html>.

A4_Handout.html

The general student handout: notes, a term table, questions, a memory hook, a sign-off. This is the one to reach for when a task is "here is some teaching, now answer these".
