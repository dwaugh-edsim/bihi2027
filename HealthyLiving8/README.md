## 1. Directory Purpose & LLM Context

This folder contains the complete curriculum, interactive diagnostic tools, classroom projector displays, and gallery walk materials for **Grade 8 Healthy Living**.

The pedagogical backbone of this course is the **"5 Dimensions of Health" Systems Model** (Physical, Mental/Emotional, Social, Spiritual, and Environmental). Rather than teaching health as isolated units, students examine how systemic habits, social ecosystems, physical environments, and personal routines create compounding health outcomes.

## 4. Technical Constraints for LLMs Modifying This Folder

1. **Self-Contained Code:** All student-facing and projector tools must run directly in the browser via file URL or GitHub Pages without server-side dependencies.
2. **High-Contrast LCD Display:** Projector displays must support high-contrast lighting to remain legible on classroom smartboards and HDMI projectors (use `#0f172a` dark mode or crisp white presentation modes).
3. **Student Privacy:** All student data displayed on projector screens must be aggregated and anonymized. Do not expose personal student PINs or student IDs on public dashboard screens.
